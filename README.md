# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.

# Myanmar Club Community Website

Responsive website for the Myanmar Club at Asia-Pacific International University (AIU), built for our Frontend course.

**Mission:** Showcase Myanmar Club Activities (festivals, fundraising, field trips, etc.) so members and visitors can discover and join them.

**Team**
- Developer 1: Saw Eh Thalay Htoo
- Developer 2: Saw Joshua

**Stack:** React, Vite, Tailwind CSS

**Run locally**
npm install
npm run dev

**Pages/sections:** Home, About Us, Events & Activities, Gallery, Join Us

# 2. Skeleton at 360 px

At a 360 px viewport, the page uses a single-column mobile layout:

- The header shows the club mark and a menu button. Navigation links open from the mobile menu.
- The Home section stacks its text and feature panel vertically.
- About Us and Events & Activities use vertically stacked content and cards.
- Gallery displays images in a two-column grid.
- Join Us stacks its content and call-to-action vertically.
- Sections keep consistent side padding and scroll below the sticky header.
